# SecondRepo

My second repository, created the same week as the first, in June 2025.

A single static page: `index.html` with a heading, a dropdown and a button,
and a `style.css` next to it. The commit history is me adding one element at
a time to see what each one did.

Kept public on purpose. The rest of this account argues that claims should be
checkable, and that includes the claim that I started from zero.

## What I was learning here

Basic HTML structure, linking a stylesheet, and using commits to mark one
change at a time rather than one large upload.
